# EDA Part 1: Myntra Product Catalog Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Myntra Product Catalog dataset using Python.

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Work
- Data inspection and understanding
- Data cleaning and handling missing values
- Exploratory data analysis
- Data visualization
- Identifying patterns and insights

## Files
- Myntra EDA Notebook (.ipynb)
- Myntra Excel Dataset (.xlsx)
- Myntra EDA Presentation (.pptx)

## Objective
To explore product data, understand distributions and relationships between variables, and extract meaningful insights.
