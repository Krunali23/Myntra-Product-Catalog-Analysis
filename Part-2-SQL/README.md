# SQL-Part-2/ Analysis

## Overview

This part focuses on analyzing the Myntra Product Catalog dataset using SQL in MySQL. The project explores 1,500 product listings to understand brand performance, pricing patterns, discount strategies, product categories, and customer ratings.

## Objectives

- Analyze product listings using SQL queries.
- Identify unique brands and compare product counts across categories.
- Explore product prices and classify products into Budget, Mid-range, and Premium segments.
- Examine the relationship between discounts and customer ratings.
- Rank brands based on total customer ratings using window functions.
- Use stored procedures to retrieve a brand's most-rated products.
- Apply subqueries to compare product prices and brand ratings.
- Derive meaningful business insights from query results.

## Files

- `Myntra_SQL_Project.sql` — SQL queries used for the analysis.
- `Myntra_SQL_Project.pptx` — Presentation containing the business questions, query outputs, insights, and conclusions.

## Tools Used

- MySQL
- MySQL Workbench

## Key Insights

- The dataset contains 1,500 products across 20 brands and 24 sub-categories.
- Mid-range products form the largest price segment, with 774 products.
- Footwear has a higher average price than clothing.
- Nike leads in total customer ratings among the analyzed brands.
- Products with discounts of 40% or more have a lower average rating than the remaining products.
- Only three brands have an average rating above 4.5.

## SQL Concepts Covered

`SELECT`, `WHERE`, `DISTINCT`, `ORDER BY`, `LIMIT`, aggregate functions, `GROUP BY`, `HAVING`, `CASE WHEN`, window functions, stored procedures, and subqueries.
